# CHJ 投稿確認の本番運用

ユーザーの「投稿の確認もちゃんとやりたい、本番仕様」と既存の本番公開承認に基づき、現在のCloudflare Pages/D1/Accessを継続する。管理者が本文・写真を確認してから公開でき、件数と処理状況を把握できるようにする。

## Approach
既存の管理画面を拡張する。外部CMSへの移行は既存D1と認証の置換が必要で、今回の投稿確認には不要。自動公開は確認してから公開する目的に合わない。新しい契約・メール送信・管理者追加は行わない。

## Behavior
- 確認待ち・公開済み・非公開の実件数を表示。新しい順に20件ずつ、続きも読み込める。
- 各投稿に対象ニュース、表示名、全文、写真、受付日時、最終処理日時、投稿IDを表示。
- 公開前には対象の全文と写真を再確認できるダイアログを表示し、確定操作後だけ保存。写真は任意。
- 非公開は取り消し可能であり削除しない。承認前・非公開の内容は引き続き一般公開しない。
- 状態と最終処理日時を条件に保存し、別画面で処理された場合は409にして再読込を案内。
- HTMLのログイン画面、403、通信失敗は保存成功にしない。再ログイン/再読込の導線を用意。
- 確認手順を管理画面内に表示し、スマートフォンでも操作できる。

実装判断: 追加の通知サービスや自動メールは範囲に含めない。新規の確認者情報を保存するスキーマ変更はせず、既存moderated_atを利用。一般公開ページの内容・DNS・メール設定は変更しない。
